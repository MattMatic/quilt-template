Print at home (actual size)

One template per unique piece, printed at true 100% scale with both the cut line and stitch line, packed across as many pages as needed. Pieces too large for one page are automatically tiled with a registration mark to line up. Every page includes a 1" calibration line — measure it before cutting to confirm your printer didn't rescale the page.

How grouping works: pieces are matched by side lengths and interior angles, so two pieces of the same size and shape end up as one template regardless of position or rotation in the original pattern.

How the allowance is added: each edge is pushed outward by the allowance amount and re-joined at the corners (a true miter), the standard way seam allowance is added to a piecing template. Very sharp points are beveled automatically so they stay printable.

Runs entirely client-side — nothing is uploaded anywhere.

How Cutting Table came together

Built interactively, one real problem at a time

  • 1. Parsing the pattern

    Started from a real 15"×15" Storm at Sea DXF with a spec of 28 pieces across 8 unique sizes. The source file only contained raw LINE segments with no piece boundaries marked, so the app reconstructs pieces itself with a planar face-tracing algorithm (the same technique used to find faces in a line arrangement), then groups congruent shapes by matching side lengths and interior angles.

  • 2. Seam allowance + DXF/SVG export

    Added a true mitered outward offset (with automatic beveling for very sharp points) and exported one template per unique size as DXF and SVG, with a cut line and a stitch-line reference.

  • 3. Fixing the Shapr3D import

    The first DXF failed to import into Shapr3D at all. The cause: DXF TEXT entities aren't supported by Shapr3D's importer, and the file used the newer AC1015 format without entity handles it expects. Switched to the universally-compatible DXF R12 format and moved piece labels off TEXT entities entirely, encoding them as layer names instead.

  • 4. One layer per piece

    Originally the cut line and stitch line for each piece sat on separate layers, so Shapr3D couldn't select both curves together to extrude the ring between them. Fixed by putting both lines for a given piece on one shared layer (distinguished only by color), so selecting a layer now selects exactly what needs extruding.

  • 5. Real 3D solids: STL + STEP

    Added direct 3D export of the seam-allowance ring itself (the space between the stitch line and cut line) extruded to a set thickness — no modeling software required. STL is a triangulated mesh validated as watertight and correctly wound; STEP is a genuine B-rep solid (points, edges, trimmed planar faces, closed shell) that was test-imported into a real CAD kernel to confirm it opens as a valid solid, not just a syntactically correct file.

  • 6. Print-at-home PDF

    Added a print-ready PDF layout: one template per unique piece at true 100% scale, packed across Letter or A4 pages, with automatic tiling and registration marks for any piece too large for one page, plus a 1" calibration line on every page to catch printer rescaling before it ruins a cut.

  • 7. This version

    Added a one-click sample loader for the original Storm at Sea pattern, this history panel, and an overall pattern-size readout alongside the piece count and unique-size count.

Every change above was driven by testing against the real pattern file and, where possible, by actually opening the generated files in independent tools (a real CAD kernel for STEP, mesh-validity checks for STL, a PDF renderer for the print layout) rather than trusting the generator alone.
